# Diabetic Related Treatment Cost

The objectives of this repository is:

-   To share the summarised findings from the journal article [Diabetic-related treatment costs and catastrophic health expenditure at a tertiary care hospital in Rajshahi, Bangladesh: a cross-sectional study](https://bmjopen.bmj.com/content/16/4/e108120)

-   Recreate the tables and plots using R so that readers can easily replicate the analysis

This is a live document and will be updating as new contents are added.
